## Users

Manga and comic readers who need in-image text translation (Japanese → Chinese). Typically casual to semi-technical users who want a simple, clean configuration experience in a browser popup.

## Product Purpose

Browser extension popup for configuring manga image translation: OCR engine selection, translation service (Google/LLM), target language, and LLM provider/model/API key settings. Auto-saves on every change. Design serves quick configuration, not marketing.

## Brand Tone

Clean, feminine, lightweight. Pink accent palette (light pink, not saturated magenta). The name "Shinobu" evokes softness. UI should feel精致 (refined) and简洁 (simple), not overwhelming.

## Anti-References

- SaaS dashboard aesthetics (dark nav, data grids, metric cards)
- Hardcore developer tool UIs (terminal themes, monospace everything)
- Generic chrome extension settings pages (plain white, no personality)

## Strategic Principles

- Every component polished, no rough edges
- Lighter pink than current implementation
- Compact popup (380px width) — density with clarity
- Auto-save feedback via subtle status bubble, not intrusive toasts
