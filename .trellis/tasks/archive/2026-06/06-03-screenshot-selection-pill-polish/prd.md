# 优化截图翻译选区与药丸状态

## 目标

让截图翻译从“调试浮层”升级为接近截图软件的轻量交互：进入截图翻译后，未手动框选前默认吸附鼠标所在页面元素；用户可以通过滚轮在父/子元素层级间切换；翻译过程和结果控制统一由现有药丸按钮表达，浮动图片跟随药丸一起显示、隐藏和关闭。

## 用户价值

- 减少手动框选成本，尤其适合漫画图片、图片容器、阅读器页面这类已经有明确 DOM 边界的场景。
- 保持 ShinobuTranslator 现有药丸按钮的状态语汇，避免截图翻译出现另一套粗糙状态面板。
- 关闭、切换、重试等操作集中到药丸按钮，用户不需要在结果图片角落寻找独立控件。
- 右键“翻译图片”作为临时区域翻译入口，始终展示浮动译图，不再依赖替换原 DOM 图片是否成功。

## 已确认事实

- 当前分支为 `codex/screenshot-context-translation`，已有截图翻译通路。
- 截图选择和结果 UI 位于 `src/content/core/ui.ts`。
- 截图矩形、裁剪和候选工具位于 `src/content/core/screenshot.ts`。
- 截图生命周期、pipeline 执行和清理位于 `src/content/core/TranslatorCore.ts`。
- 内容脚本必须使用 imperative DOM 和 `mt-x-` 前缀 CSS，不引入 React。

## 需求

- 进入截图翻译后，不显示顶部提示，也不显示独立右上角取消按钮。
- 未手动拖拽框选前，选区默认吸附鼠标所在元素边界。
- 鼠标滚轮用于切换元素层级：向上滚切到父级或更大的元素，向下滚切到子级或更小的元素。
- 截图选择框线使用超粗深灰色线，颜色参考药丸描边，外侧不再有白色描边；视觉上可有轻微圆角，但实际截图区域仍按方形矩形计算。
- 非选中区域的暗色遮罩要更暗，增加选区对比。
- 手动拖拽框选仍可覆盖默认元素吸附结果；自动或手动框选完成后进入待确认状态，不立刻开始翻译。
- 待确认状态允许通过边角/边缘热区二次调整选区大小，也允许拖动选区移动位置；热区功能保留但不显示圆形手柄，响应范围至少覆盖黑色粗描边。
- 待确认状态提供亮色药丸样式的 lucide 风格对勾确认和叉号重新框选；两个圆形按钮 hover 时圆圈加深，在选区内双击也作为快捷确认。
- 截图、裁剪、OCR、翻译、修复、排版等运行状态必须显示在药丸按钮中，不再显示截图框中央状态文字。
- 未开启耗时/调试显示时，翻译完成后不显示药丸下方的“翻译完成”小字；开启耗时显示时仍显示完成和耗时详情。
- 触发截图翻译或右键“翻译图片”后，目标区域必须进入浮动覆盖层：截图前可短暂显示同尺寸占位，裁剪完成后立即显示该区域原图，翻译完成后在同一位置切换为译图。
- 失败状态沿用原有药丸设计：按钮可重试，错误详情显示为药丸下方详情，不使用红色轻提示。
- 翻译完成后，浮动译图和药丸按钮作为同一个结果组件显示。
- 移除浮动图片右上角的大 `x` 关闭按钮。
- 药丸按钮右上角提供小圆形 `x`，点击后药丸和浮动图片一起消失，并清理状态和 object URL。
- 右键菜单必须同时保留“翻译图片”和“截图翻译”两个入口。
- 右键“翻译图片”统一使用截图浮动结果层，不再替换原 DOM 图片。
- 右键目标是 `img` 或非 `img` 时，都按右键区域生成 `ScreenshotSelection`，然后走截图翻译浮动结果层。
- 站点适配器自动挂载的药丸仍保留原地替换能力；右键菜单只作为临时区域翻译入口。
- 药丸右上角小圆形 `x` 不使用阴影。
- 药丸右上角小圆形 `x` 需要更小，`x` 字符本身在圆形内的占比也更小。
- 药丸右上角小圆形 `x` 需要贴近药丸本体。
- 药丸右上角小圆形 `x` 使用 lucide 风格 SVG，图标颜色为选区描边深灰；按钮参考药丸本体配色，hover 时整颗按钮覆盖一层暗色。
- 浮动结果组件可继续拖动位置，拖动作用于药丸和图片组合。
- 所有用户可见文案使用中文。

## 验收标准

- [ ] 触发“截图翻译”后，鼠标移动到页面元素上会自动高亮该元素边界，无需先拖拽。
- [ ] 自动元素选区状态下，滚轮向上会选中更上层/更大的候选元素，滚轮向下会回到更下层/更小的候选元素。
- [ ] 截图选择框线为超粗深灰线，没有白色外描边，视觉圆角不影响实际方形截图区域。
- [ ] 非选中区域遮罩明显变暗。
- [ ] 手动拖拽框选仍可用，并优先于元素吸附结果；松手后进入待确认/调整状态。
- [ ] 自动元素选区点击后进入待确认/调整状态。
- [ ] 待确认状态下可通过不可见热区调整大小，热区覆盖深灰粗描边，可点击亮色药丸内的 lucide 风格对勾确认，可点击叉号重新框选，按钮圆圈 hover 加深。
- [ ] 在待确认选区内双击会快捷确认。
- [ ] 翻译运行状态显示在药丸按钮中，不再显示截图框中央状态文字。
- [ ] 未开启耗时/调试显示时，成功后药丸下方没有“翻译完成”详情行。
- [ ] 触发截图翻译或右键“翻译图片”后，对应区域会进入浮动覆盖层；裁剪完成后显示原图，翻译完成后同一浮动图片切换为译图，截图瞬间不会把覆盖层捕获进源图。
- [ ] 失败后药丸显示“重试”语义，并沿用原有失败样式。
- [ ] 翻译成功后，结果图片与药丸按钮作为同一个浮动组件显示。
- [ ] 点击药丸右上角小 `x` 会同时移除图片和药丸。
- [ ] 药丸右上角小 `x` 尺寸更小、无阴影、贴近药丸，使用 lucide 风格 SVG，图标为描边深灰，hover 时整颗按钮暗化。
- [ ] 右键菜单里“翻译图片”和“截图翻译”两个入口都可见。
- [ ] 右键“翻译图片”始终显示截图浮动结果层，不替换原 DOM 图片。
- [ ] `img` 和非 `img` 元素上触发“翻译图片”时，结果都显示在浮动层中。
- [ ] 原浮动图片右上角独立关闭按钮不存在。
- [ ] 关闭后对应 `PhotoState` 被删除，`translatedUrl` / `debugOriginalUrl` / 截图原图 object URL 被释放。
- [ ] 新增纯函数测试覆盖元素候选排序、层级切换、矩形归一化或过滤逻辑。
- [ ] `npx tsc --noEmit`、`npm run test`、`npm run build` 通过。

## 非目标

- 不新增截图翻译的 popup 设置项。
- 不改变后台 `mt:capture-visible-tab` 消息协议。
- 不新增第三方截图库。
- 不修改站点适配器自动挂载药丸的原地替换行为。

## 开放问题

暂无阻塞问题。默认保留 `Esc` 作为取消截图选择的键盘退路，但不在界面顶部显示提示。
